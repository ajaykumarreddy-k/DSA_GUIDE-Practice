# 15-Day DSA "Zero to Hero" Mastery Program

This 15-day curriculum is tailor-made based on the specific computer science and placement materials found in your folder. By intelligently allocating the provided books, handwritten notes, and code snippets, this plan ensures you comprehensively cover the data structure and algorithmic (DSA) models required to crack interviews.

## Core Resources to Utilize (Found in your directory)
1. **DSA Handwritten guide(Beginner to Advanced).pdf** (Your primary theory roadmap)
2. **Durgasoft python book .pdf** (Comprehensive Python syntax and structures reference)
3. **Algorithm notes for professionals(257pgs).pdf** (For optimizing time and space complexities)

## 🎯 Phase 1: Logic Building & Concrete Foundations (Days 1 - 4)

### Day 1: Python Syntax Brush-up & Complexity Analysis
- **Study Material:** `Durgasoft python book .pdf` & `100 python interview questions .pdf`
- **Topics Covered:** Variables, Loops, Conditionals, Functions, Time & Space Complexity (Big O Notation).
- **Practical Goal:** Understand how Python manages memory. Determine the Big O of basic loops. Implement 5 basic math/logic problems (factorial, fibonacci, prime check, palindrome, swap) to build muscle memory.

### Day 2: Array Mastery
- **Study Material:** `C arrays q_a with explana.pdf` & `DSA Handwritten guide(Beginner to Advanced).pdf`
- **Topics Covered:** 1D Arrays, 2D Arrays, Array traversal, In-place operations.
- **Practical Goal:** Solve questions like: Reverse an array, Find Maximum/Minimum elements, Move zeros, Two-sum, Matrix traversal / Spiral Matrix.

### Day 3: Searching & Sorting Deep Dive
- **Study Material:** `Algorithm notes for professionals(257pgs).pdf`
- **Topics Covered:** Linear Search, Binary Search, Bubble Sort, Selection Sort, Insertion Sort, Merge Sort basics.
- **Practical Goal:** Implement Binary Search recursively and iteratively. Understand the O(N log N) advantage of efficient sorting. Follow the code in your algorithmic notes.

### Day 4: Strings & Two-Pointer Technique (Python)
- **Study Material:** `100 python interview questions .pdf` & `Cracking the Coding Interview.pdf` (Chapter 1)
- **Topics Covered:** ASCII basics, Python string immutability, String slicing/methods, Two-pointer technique.
- **Practical Goal:** Palindrome checking using slice (`s[::-1]`), Anagram validation using `Counter`, Longest substring without repeating characters using two pointers.

## 🏗️ Phase 2: Core Data Structures (Days 5 - 9)

### Day 5: Linked Lists (Singly)
- **Study Material:** `DSA Handwritten guide(Beginner to Advanced).pdf`
- **Topics Covered:** Dynamic memory allocation, Insertion, Deletion, and Traversal in a Singly Linked List.
- **Practical Goal:** Write a Linked List implementation from absolute scratch. Solve: Reverse a linked list, Find the middle node.

### Day 6: Linked Lists (Advanced)
- **Study Material:** `Cracking the Coding Interview.pdf` (Linked Lists Chapter)
- **Topics Covered:** Doubly Linked Lists, Circular Linked Lists, Slow & Fast Pointers.
- **Practical Goal:** Detect cycle in a linked list (Floyd's algorithm), Merge two sorted linked lists, Remove the Nth node from the end.

### Day 7: Stacks & Queues
- **Study Material:** `DSA Handwritten guide(Beginner to Advanced).pdf` & `Imp coding questions with solutions .pdf`
- **Topics Covered:** LIFO and FIFO concepts, implementing stacks using arrays and queues.
- **Practical Goal:** Solve Next Greater Element, Valid Parentheses, Implement a Queue using Stacks.

### Day 8: Mid-Program Mega Revision
- **Study Material:** Mixed Review
- **Practical Goal:** Do not learn anything new today. Instead, blind-test yourself on arrays, searching, sorting, linked lists, stacks, and queues. Use `Imp coding questions with solutions .pdf` to simulate mini interviews.

### Day 9: Intro to Trees
- **Study Material:** `DSA Handwritten guide(Beginner to Advanced).pdf`
- **Topics Covered:** Basic Binary Tree Structure, Traversals (In-order, Pre-order, Post-order).
- **Practical Goal:** Write traversal models recursively. Find the maximum depth/height of a tree, check if two trees are identical.

## 🚀 Phase 3: Advanced Architectures & Algorithms (Days 10 - 15)

### Day 10: Binary Search Trees (BST) & Heaps
- **Study Material:** `Algorithm notes for professionals(257pgs).pdf`
- **Topics Covered:** BST properties, Heap properties (Min-Heap / Max-Heap), Priority Queues.
- **Practical Goal:** Search/Insert into a BST, Validate if a tree is a BST, Find Kth largest element using Heaps/Priority Queues.

### Day 11: Graphs (The Basics)
- **Study Material:** `DSA Handwritten guide(Beginner to Advanced).pdf`
- **Topics Covered:** Graph representations (Adjacency List vs Matrix), Breadth-First Search (BFS), Depth-First Search (DFS).
- **Practical Goal:** Implement BFS and DFS. Solve the "Number of Islands" problem or basic matrix traversal.

### Day 12: Graphs (Advanced Routing)
- **Study Material:** `Algorithm notes for professionals(257pgs).pdf`
- **Topics Covered:** Shortest Path (Dijkstra's Algorithm), Cycle Detection in Directed/Undirected Graphs, Topological Sort.
- **Practical Goal:** Understand routing on graphs. Re-implement cycle detection concepts and trace Dijkstra's on paper.

### Day 13: Recursion & Backtracking
- **Study Material:** `Cracking the Coding Interview.pdf` 
- **Topics Covered:** Decision Trees, Backtracking templates.
- **Practical Goal:** Solve purely recursive algorithms like Permutations of a string, N-Queens basics, and Sudoku Solver logic.

### Day 14: Dynamic Programming (DP)
- **Study Material:** `Algorithm notes for professionals(257pgs).pdf` & `Imp coding questions with solutions .pdf`
- **Topics Covered:** Top-Down (Memoization) vs Bottom-Up (Tabulation), Overlapping subproblems.
- **Practical Goal:** Start with basics: Climbing Stairs, Fibonacci series, Coin Change, Longest Common Subsequence (LCS). The goal is to see the pattern, not memorize the code.

### Day 15: Mock Interviews & "Hero" Deployment
- **Study Material:** `cracking interview.pdf`
- **Topics Covered:** Overall application, Edge cases, Behavioral integration, DB basics (`Dbms interview questions .pdf`).
- **Practical Goal:** You've built the muscle. Today, pick 4 random hard/medium questions from `Cracking the Coding Interview.pdf`. Do white-board coding (use pen and paper, no IDE). Speak out loud while solving to simulate actual interview conditions.

**Tips for Maximum Retention:**
- **Code Every Day:** Never let a day pass without typing out algorithms.
- **Use Pen & Paper:** For Trees, Graphs, and Linked Lists, trace the pointers visually on paper.
- **Time Check:** If you are stuck on a problem for more than 45 minutes, look at the solution in the provided `.pdf` files, understand it logically, and code it yourself.
